## 衔接与内容

接在第二部分“小结二”之后。第1—4页讲述楼宇服务如何积累信任、青年怎样参与治理，以及党团组织的分工。第5、6页以2022年上海青年服务历史实景说明需求回应、专业参与和培训协作；这些场景与高和大厦、越洋广场主案例明确区分。第7页回到电话号码小纸条，给出团支部可以采取的四步行动；第8页归纳全课并结束。
